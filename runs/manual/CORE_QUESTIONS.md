# Core question set — ask ALL of these on EVERY platform

Ten questions. Same ten everywhere. That is the whole point: if the
questions differ per platform, the comparison between platforms means nothing.

## Rules

- **New chat for every question.** A continuing thread contaminates the next answer.
- **No custom Space, no custom instructions, no 'panel' mode.** Plain default chat.
- If the platform has a model selector, note which model you used.
- Copy the *entire* answer including its sources.
- Partial is fine. One platform fully done beats five half-done.

## Where answers go

`runs/manual/<platform>/answers/<id>_0.txt` — the files already exist, empty.
