For each question:

1. Copy the question text below
2. New Perplexity chat -> paste -> enter
3. Copy Perplexity's whole answer, including its sources
4. Open the matching file in `answers/` and paste it in, then save

No terminal needed. Partial is fine — do as many as you have patience for.
